# Reproducing the figures

Every figure of the paper is regenerated by

```bash
python make_all_figures.py
```

from a clean environment created with `requirements-lock.txt`. Individual
figures can be requested by number.

## Expected numbers

Anything reproducing this repository should recover the following.

**Kinematics** (`python kinematics.py`)

```
theta      gamma      E[MeV]     gd(th)     q3/t
  1.00     1.5431     0.7885     0.8658    -0.2723
  5.00    74.2099    37.9212     1.5573    -0.0000
```

**Trajectory invariants** (`python dynamics.py`, plane wave, `L = 5λ`)

```
 LT a0= 0.85  gamma_max=    1.181  |E^2-P^2-1|max ~ 1e-16  |gamma-Pz-1|max ~ 1e-10
WNL a0= 8.50  gamma_max=   19.132  |E^2-P^2-1|max ~ 1e-14  |gamma-Pz-1|max ~ 1e-09
 UR a0=85.00  gamma_max= 1814.187  |E^2-P^2-1|max ~ 1e-10  |gamma-Pz-1|max ~ 1e-09
```

`γ_max` converges to the closed form `1 + a₀²/4` as the envelope lengthens:
relative excess `3.8e-3` at `L = 5λ`, `7.7e-4` at `10λ`, `1.1e-5` at `20λ`.

**Radiation-reaction parameters** (`python rr.py`, `λ = 1 μm`)

```
eps_rad = 1.180e-08     eps_ph = 2.426e-06
LT  a0= 0.85  chi=2.06e-06  R=7.25e-09
WNL a0= 8.50  chi=2.06e-05  R=7.25e-06
UR  a0=85.00  chi=2.06e-04  R=7.25e-03
```

**Measured effect of the Landau–Lifshitz force** on `θ_max`
(`data/rr_effect.json`; `L = 5λ`)

| polarization | H₀ | LT | WNL | UR |
|--------------|-----|-----|------|------|
| circular | 0 | +0.00 % | +0.00 % | +0.01 % |
| circular | 1 | −0.01 % | −0.79 % | **−12.53 %** |
| linear | 0 | +0.00 % | +0.00 % | +0.01 % |
| linear | 1 | −0.01 % | −0.38 % | **−9.98 %** |

Reading: with no static field the back-reaction is negligible even at
`a₀ = 85`, because `γ − P_z = 1` caps `χ` at `2×10⁻⁴`. Under the resonant
cyclotron lock the classical model overestimates the rapidity reached by more
than 10 %, and radiation reaction must be included there.

**Critical frequencies** (`python spectra.py`)

```
 LT  omega_c,max = 1.065e+00 omega   (1.3e-3 keV)
WNL  omega_c,max = 1.725e+02 omega   (2.1e-1 keV)
 UR  omega_c,max = 1.636e+05 omega   (2.0e+2 keV)
```

## Figures whose content changed in this revision

The scripts here do **not** reproduce the submitted PDFs pixel for pixel.
For five figures that is deliberate: the submitted versions were defective.
Each script carries a `NOTE ON THE PUBLISHED VERSION` block; summarized:

| Fig. | Defect in the submitted version | Replacement |
|------|--------------------------------|-------------|
| 4 | Twelve different narrow time windows; panel (a) annotated `max = 4.44e-18` — floating-point round-off amplified to full scale; panel (i) `max = 5.00e+02` — spikes of a diverging closed-form expression. | Direct DOP853 integration on a single common abscissa (`η/L`), plotting the rapidity `θ`, with a radiation-reaction overlay. |
| 5 | Panel (b) contained a singular spike to `y/λ = −100` that compressed every other curve onto the axis. | Integration for both the co- and counter-propagating channel. |
| 7 | "Spectral power" reached `−1.0`; `W̃ = \|∫…\|²` cannot be negative. Abscissa ran over negative frequencies. | Non-negative synchrotron spectrum vs absolute photon energy, plus the collapse onto the universal shape. |
| 8 | "Directionality functions" of order `1e20`–`1e21`, non-zero only in one spike near `θ = 2.1`; five of six curves invisible. | Liénard–Wiechert angular distribution vs observation angle, for the intensity, static-field and pulse-width series. |
| 9 | Output labelled `β⊥, β_s, θ` and objective `L_ODE + …`; the code outputs `(P̂ₓ, P̂ᵧ, P̂_z, γ̂, η̂)` and minimizes the data-augmented objective. | Schematic redrawn to match the implementation. |

Two further changes are improvements rather than corrections:

- **Fig. 3** — the published map had no documented defining formula. The
  closed form is now written out in the script, and an alternative
  first-principles map computed from the equations of motion is available via
  `--ode`.
- **Fig. 6** — line brightness now encodes the local pulse intensity, which
  the published caption described but the published figure did not show.

## Known limitations

- The `--ode` synchronization map (Fig. 3′) uses a 60×40 grid; the analytic
  map uses 400×400. They agree on the location and broadening trend of the
  resonance but not point by point, since they measure different things
  (retained energy fraction vs. a resonance-width interpolation).
- Figure 8 panel (c) shows an almost degenerate pulse-width series. This is
  physical: in the plane-wave limit the emission angle is fixed by the local
  field amplitude, not by the envelope length. It is reported rather than
  suppressed.
- The Landau–Lifshitz implementation keeps only the `γ²`-dominant term. This
  is standard for validity estimates and is accurate to `O(γ⁻²)` relative;
  it is not a substitute for a full QED treatment where `χ ≳ 0.1`.
